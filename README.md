## 🌟 Overview

**FlowSite** is a professional, AI-enhanced website builder designed for the "Zero-Dependency" era. It empowers developers, students, and businesses to create stunning, high-performance websites and export them as clean, single-file HTML documents ready for instant hosting.

Unlike traditional builders that lock you into complex frameworks or expensive hosting, FlowSite delivers **Instant Creation, Infinite Portability.**

## 🚀 Key Upgrades (May 2026)

The latest version of FlowSite introduces a suite of "Pro" features:

### 1. 🤖 Gemini AI Profile Scanner
Struggle with writing your bio or listing skills? Simply upload a screenshot of your LinkedIn profile or resume. FlowSite uses **Gemini 1.5 Flash** to intelligently parse your data and automatically populate the entire editor in seconds.

### 2. ⚡ High-Fidelity Export Engine
Exporting a website now generates a "Production-Ready" single file including:
*   **Animated Glassmorphism:** Real-time CSS backdrop filters and glass effects.
*   **Floating Backgrounds:** Dynamic, CPU-optimized animated shapes.
*   **SEO Meta Injection:** Automatic Open Graph, Twitter Cards, and JSON-LD structured data for perfect search engine visibility.
*   **Zero-Dependency Logic:** No external JS libraries required in the exported file—just pure, blazing-fast Vanilla HTML/CSS/JS.

### 3. 📱 Professional Device Preview
Switch instantly between **Mobile, Tablet, and Desktop** views with a polished device frame (complete with an iPhone-style notch). Preview exactly how your site will look on any screen before you export.

### 4. 🎨 Professional Editor Experience
*   **Section Reordering:** Drag-and-drop sections to reorganize your layout using `@dnd-kit`.
*   **Sub-template Variants:** Choose from multiple layouts for Hero and Skills sections (Centered, Split, Minimal, Grid, Bars, Tags).
*   **Avatar Editor:** Integrated cropping and optimization to ensure your profile picture looks perfect without slowing down your site.

### 5. 🛠️ One-Click Deployment Tools
The new multi-step export modal provides guided instructions for hosting your site for free on **GitHub Pages, Netlify Drop, or Vercel**, plus a built-in **QR Code Generator** for easy mobile sharing.

## 🛠️ Technical Stack

*   **Frontend:** React 19 + Vite 6
*   **Styling:** Tailwind CSS v4 (next-gen performance)
*   **AI:** Google Gemini 1.5 Flash
*   **3D Graphics:** Three.js / React Three Fiber
*   **Animations:** Motion (Framer Motion)
*   **Notifications:** Sonner
*   **Performance:** Manual Chunk Splitting & Optimized Asset Bundling

## 📁 Getting Started (Local Development)

1.  **Clone & Install:**
    ```bash
    git clone https://github.com/itssagarK/flowsite.git
    npm install
    ```
2.  **AI Configuration:**
    Add your `VITE_GEMINI_API_KEY` to a `.env.local` file.
3.  **Run:**
    ```bash
    npm run dev
    ```
4.  **Build for Production:**
    ```bash
    npm run build
    ```
